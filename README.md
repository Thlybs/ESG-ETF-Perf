# Green ETFs Analysis

## Project Overview

This project aims to analyze **Green ETFs (Exchange-Traded Funds)**, focusing on their financial performance and overlap. The goal is to provide insights into how these ETFs perform over time and how they compare to each other in terms of holdings and sustainability metrics.

⚠️ **Note:** This project is currently in its **early stages** and is actively being developed. New features, improvements, and analyses will be added over time.

---

## Features

- **Performance Analysis**: Historical performance metrics of selected Green ETFs.
- **Overlap Analysis**: Identification of common holdings across different Green ETFs.
- **Visualizations**: Interactive charts and graphs to visualize trends and overlaps.
